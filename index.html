Install Timetable App

Mobile (Android / iPhone):

  1. Open this site in Chrome (Android) or Safari (iPhone).
  2. Tap the Share or Menu (⋮) button.
  3. Select "Add to Home Screen" or "Install App".

Desktop (Windows / Mac):

  1. On Chrome / Edge, click the Install icon in the address bar (or Menu → Apps → Install this site).
  2. Or simply run the Open-Timetable-App.bat file in this folder to launch in native app mode!
